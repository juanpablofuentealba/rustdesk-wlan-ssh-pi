------------------------------------------------------------------------
  AUTH KEY DE TAILSCALE: ACA SE GENERA (no en el equipo)
------------------------------------------------------------------------

     https://login.tailscale.com/admin/settings/keys

  Se crea en esa PAGINA WEB, con tu cuenta, desde cualquier navegador (el
  celular sirve) y se copia. Camino manual: admin -> Settings -> pestana
  "Keys" -> "Generate auth key". Se muestra UNA SOLA VEZ.

  Sin key todavia? No te bloquees:
     sudo ./instalar-todo.sh --tailscale-luego --rdpass 'MiClave2026'
     ./unir-tailscale.sh --hostname <equipo>     # pide la key y une

------------------------------------------------------------------------
  QUE HAY EN ESTE PENDRIVE
------------------------------------------------------------------------

  1) REPO.txt             <- El repositorio: URL, uso rapido, indice
  2) PASOS-EN-ORDEN.txt   <- EMPIEZA ACA. Los pasos, en orden.
  3) kit-rustdesk/        <- El kit (scripts + runbook detallado)
  4) PROMPT-AGENTE.txt    <- Si usas un agente IA (OpenCode/Claude/pi)
  5) ISOs arrancables     <- Para instalar el sistema operativo

  Las ISOs NO se copian: se ARRANCAN. La carpeta kit-rustdesk/ se COPIA
  al PC ya instalado.

  REPOSITORIO:  https://github.com/juanpablofuentealba/rustdesk-wlan-ssh-pi

------------------------------------------------------------------------
  RESUMEN EN 4 LINEAS
------------------------------------------------------------------------

  1. Arranca el pendrive -> instala el SO CON WiFi
  2. Reinicia sin el pendrive -> conecta la red
  3. Copia el kit:  cp -r /run/media/$USER/Ventoy/kit-rustdesk ~/kit
  4. UN SOLO COMANDO:

       cd ~/kit
       sudo ./instalar-todo.sh --authkey 'tskey-auth-XXXX' --rdpass 'MiClave2026'

     (--all ya incluye anti-suspension de portatil). Detalle en
     PASOS-EN-ORDEN.txt o kit-rustdesk/INSTALAR.md

------------------------------------------------------------------------
  ANTES DE SALIR DE CASA
------------------------------------------------------------------------

  [ ] Auth key de Tailscale      (tskey-auth-...)
  [ ] Contrasena permanente de RustDesk que le vas a poner
  [ ] Contrasena de sudo que elegiras al instalar el SO
  [x] Tu clave publica SSH       (ya viene en kit-rustdesk/operador.pub)

  PRUEBAS DESDE TU EQUIPO OPERADOR (despues de instalar):
     ./verify-offlan.sh <hostname>           acceso fuera de la LAN (7 OK)
     ./reboot-remoto.sh --host ... --all     prueba de reinicio unattended

------------------------------------------------------------------------
  SI ALGO FALLA
------------------------------------------------------------------------

  "no hay aur helper paru"
     -> Ya NO es problema: el kit usa el .deb oficial sin AUR. Si falla
        igual, es falta de RED:  curl -sI https://github.com | head -1

  "tailscale no une"
     -> El kit muestra el error real. Causas: key vencida, no reusable,
        o sin internet. La key se genera en la WEB (ver arriba).

  "Wayland portal handshake failed"
     -> Falta el capturador DRM. El kit lo detecta y dice como arreglarlo.

  "Pide aceptacion en cada conexion"
     -> Falta la contrasena permanente de RustDesk (paso del --rdpass).

  "RustDesk failed tras instalar"
     -> Puede ser la sesion grafica caida. Reinicia y: systemctl status
        rustdesk. Documentado en docs/hallazgos.md.

  "No puedo reiniciar el equipo por SSH (pide contrasena)"
     -> Normal: sudo pide clave y polkit exige auth interactiva (H-27).
        Usa:  ./reboot-remoto.sh --host USUARIO@IP --enable   (una vez)

  "verify-offlan dice directo pero es la misma red"
     -> Si operador y objetivo tienen la MISMA IP publica, es la misma casa
        y la prueba NO vale. Compara:  curl -s https://api.ipify.org

  Diagnostico completo:  cd ~/kit && ./setup-remote-target.sh --check
  Todos los problemas conocidos:  docs/hallazgos.md

  Verificar el kit:  cd kit-rustdesk && sha256sum -c MANIFEST.sha256

========================================================================
  REPOSITORIO DEL PROYECTO  (esto es lo primero que tenes que ubicar)
========================================================================

  https://github.com/juanpablofuentealba/rustdesk-wlan-ssh-pi

  Todo lo de este pendrive sale de ahi: los scripts, el runbook y la
  explicacion tecnica de cada decision (los "hallazgos verificados").
  El pendrive es el RESPALDO; el repo es la fuente de verdad.


  ----------------------------------------------------------------------
  USO RAPIDO (si tenes internet en el equipo del cliente)
  ----------------------------------------------------------------------

     git clone https://github.com/juanpablofuentealba/rustdesk-wlan-ssh-pi ~/kit
     cd ~/kit
     sudo ./instalar-todo.sh --authkey 'tskey-auth-XXXX' --rdpass 'MiClave2026'

  Si vas a usar un AGENTE IA (OpenCode/Claude/pi), pega primero:
     cat PROMPT-AGENTE.txt      <- reglas duras + flujo


  ----------------------------------------------------------------------
  SI NO TENES INTERNET (o preferis el pendrive)
  ----------------------------------------------------------------------

     cp -r /run/media/$USER/Ventoy/kit-rustdesk ~/kit
     cd ~/kit && ./setup-remote-target.sh --check


  ----------------------------------------------------------------------
  QUE HAY EN EL REPO
  ----------------------------------------------------------------------

  -- Empezar aca --
  README.md                guia general
  PASOS-EN-ORDEN.txt       checklist de pasos, en orden
  INSTALAR.md              runbook detallado
  PROMPT-AGENTE.txt        reglas para agentes IA (OpenCode/Claude/pi)

  -- El kit --
  instalar-todo.sh         UN COMANDO hace todo en el cliente
  setup-remote-target.sh   RustDesk + SSH + firewall + Tailscale (+ --laptop)
  rustdesk-password.sh     contrasena permanente de RustDesk
  install-rustdesk-unattended-fedora.sh   Fedora/RHEL con capturador DRM
  laptop-no-suspend.sh     portatiles: evita que suspenda y se pierda acceso
  unir-tailscale.sh        unir a la tailnet pidiendo/pegando la auth key
  inventory.sh             ficha de specs del equipo
  make-kit.sh              empaquetar el kit para un pendrive

  -- Verificacion --
  tests.sh                 pruebas (mas de 390)
  verify-offlan.sh         probar el acceso desde fuera de la LAN
  reboot-remoto.sh         prueba de reinicio unattended (NOPASSWD acotado)
  verify-docs.sh           valida comandos y URLs de la doc

  -- Documentacion --
  docs/hallazgos.md        H-01..H-30: problemas y soluciones verificadas
  docs/tailscale.md        acceso remoto sin abrir puertos
  docs/onboarding-cliente.md  como dar de alta un cliente (modelo B)
  docs/estado-sesion.md    estado del trabajo, para retomar
  docs/guia-desde-cero.md  explicacion para principiantes
  docs/vpn-remoto.md       WireGuard / Cloudflare como alternativas


  ----------------------------------------------------------------------
  VERIFICAR QUE ESTE KIT NO ESTA CORRUPTO
  ----------------------------------------------------------------------

     cd kit-rustdesk && sha256sum -c MANIFEST.sha256
     cat kit-rustdesk/.kit-version       # version y fecha del kit


  ----------------------------------------------------------------------
  ORDEN DE LECTURA SUGERIDO (si es la primera vez)
  ----------------------------------------------------------------------

     1. LEEME-PRIMERO.txt        (esto, resumido)
     2. PASOS-EN-ORDEN.txt       (los pasos, en orden)
     3. PROMPT-AGENTE.txt        (si usas un agente IA)
     4. docs/hallazgos.md        (si algo falla)

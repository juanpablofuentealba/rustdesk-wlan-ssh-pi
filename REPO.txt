  el hash y recien despues ejecuta con sudo:
     curl -fsSL -o /tmp/onboarding.sh https://raw.githubusercontent.com/\
       juanpablofuentealba/rustdesk-wlan-ssh-pi/main/onboarding.sh
     sha256sum /tmp/onboarding.sh          # comparar con el hash publicado
     sudo bash /tmp/onboarding.sh --nombre c --rdpass 'X' --authkey-stdin \
       --ref v1.1.1 --sha256 <hex-del-tarball>
  Offline:  sudo bash /tmp/onboarding.sh --local /ruta/al/kit ...

  ======================================================================
   ***  AUTH KEY DE TAILSCALE: ACA SE GENERA (no en el equipo)  ***
  ======================================================================

     https://login.tailscale.com/admin/settings/keys
     (alias: https://console.tailscale.com/admin/settings/keys)

  Se crea en esa PAGINA WEB, con tu cuenta, desde cualquier navegador (el
  celular sirve). Despues se copia y se pega en el equipo del cliente.
  Camino manual: admin -> Settings -> pestana "Keys" -> "Generate auth key".
  Se muestra UNA SOLA VEZ.   Reusable: SI (varios) / NO (un equipo).

  Sin key todavia? No te bloquees:
     sudo ./instalar-todo.sh --tailscale-luego --rdpass 'MiClave2026'
     ./unir-tailscale.sh --hostname <equipo>     # pide la key y une

  Detalle: README.md (seccion "Auth key de Tailscale") y docs/tailscale.md

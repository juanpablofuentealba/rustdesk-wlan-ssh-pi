  PARA QUE SIRVE

  Todo lo de este pendrive sale de ahi: los scripts, el runbook, y la
  explicacion tecnica de cada decision (los "hallazgos verificados").


  ----------------------------------------------------------------------
  CUANDO USARLO
  ----------------------------------------------------------------------

  1. Si algo falla en el PC del cliente
     -> el repo tiene la lista de problemas conocidos y como resolverlos
        docs/hallazgos.md

  2. Si queres la version mas nueva del kit
     -> clonar y regenerar el kit:

        git clone https://github.com/juanpablofuentealba/rustdesk-wlan-ssh-pi
        cd rustdesk-wlan-ssh-pi
        ./make-kit.sh --dest /run/media/$USER/PENDRIVE/kit-rustdesk --with-key

  3. Si no tenes el pendrive a mano
     -> desde el propio PC del cliente (necesita internet):

        git clone https://github.com/juanpablofuentealba/rustdesk-wlan-ssh-pi ~/kit
        cd ~/kit
        sudo ./instalar-todo.sh --authkey 'tskey-auth-XXXX' --rdpass 'MiClave2026'

  4. Solo bajar un script actualizado sin clonar todo:

        curl -fsSL -o setup-remote-target.sh \
          https://raw.githubusercontent.com/juanpablofuentealba/rustdesk-wlan-ssh-pi/main/setup-remote-target.sh


  ----------------------------------------------------------------------
  QUE HAY EN EL REPO

  README.md                guia general

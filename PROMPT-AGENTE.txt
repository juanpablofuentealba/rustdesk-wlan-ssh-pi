--- REGLAS DURAS ---

1. FIREWALL: Fedora/RHEL usan firewalld; Debian/Ubuntu/Arch usan ufw.
   El kit lo detecta solo. NO instales ufw en Fedora ni al revés.

2. RUSTDESK EN FEDORA: debe usar el paquete .deb con capturador DRM
   (install-rustdesk-unattended-fedora.sh), NO el .rpm estándar, que NO
   trae libdrmtap (ver H-14 y H-24). Verificá en el log:
       drm: consumer cache warmed (N displays) at startup

3. SHELL DEL OBJETIVO: puede ser fish. Mandá los comandos remotos por
   `bash -s` por stdin, NUNCA pegando bash suelto (ver H-23). Ejemplo:
       ssh USUARIO@IP bash -s <<'EOF'
       ... comandos ...
       EOF

4. NO REINICIES el equipo sin avisar. Si hace falta la prueba de reinicio,
   usá ./reboot-remoto.sh (ver H-27) y avisá antes.

5. NUNCA copies comandos multilínea largos pegados por SSH: se parten y
   rompen (ver H-27). Usá scp de un script + ejecutarlo, o git clone.

6. LA CONTRASEÑA DE RUSTDESK la elige el operador (--rdpass). No viene de
   ningún panel. La AUTH KEY de Tailscale sale del panel web del cliente:
       https://login.tailscale.com/admin/settings/keys
       admin -> Settings -> pestaña "Keys" -> Generate auth key
   (ver H-26 en docs/hallazgos.md). Solo se muestra UNA VEZ.

7. SUDO: en un equipo recién instalado, sudo pide contraseña y systemctl
   reboot/logind exigen auth interactiva (polkit). No es un bug (H-27).

8. Clave SSH del operador: ya viene en operador.pub. No hay que generarla.

9. PORTÁTIL: si el objetivo es un portátil, cerrar la tapa o dejarlo inactivo
   lo suspende y se PIERDE el acceso (ver H-29). El flag --laptop (incluido en
   --all) lo evita. Si instalas a mano, corré ./laptop-no-suspend.sh --apply.

10. LA AUTH KEY NO SALE DEL EQUIPO (H-30): se crea en la WEB de Tailscale
    (login.tailscale.com -> Settings -> pestaña Keys) desde cualquier navegador
    y se copia. NO hace falta tener Tailscale instalado para generarla. Si no
    la tenés a mano, NO uses --authkey: usá --tailscale-luego (instala TS sin
    unir) y después ./unir-tailscale.sh. Así no te quedás a mitad.
